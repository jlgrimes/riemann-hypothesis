# Eigenvector Anatomy of Near-Zero Eigenvalues

## Configuration

- **mpmath precision**: 30 digits
- **Zeta zeros used**: 200
- **Near-zero eigenvectors analyzed**: 5 per configuration
- **Total computation time**: 45.7s (0.8min)

## Method

For each P_0, we build the Weil matrix, project onto the primitive subspace,
and compute a full eigendecomposition. We then extract the eigenvectors whose
eigenvalues are closest to zero (excluding the trivial zero from projection).

For each near-zero eigenvector c, we analyze:
1. **Dominant indices**: which (p,m) pairs carry the largest |c_i|
2. **Weighted coefficients**: c_weighted_i = c_i * sqrt(log p) / p^{m/2}
3. **Concentration**: does weight concentrate on large primes or high powers?
4. **Spectral weight**: |G_c(tau)|^2 where G_c(tau) = sum_i c_i * w_i * exp(i*tau*x_i)
